# Escena VR SERVER BLENDER

Escena WebXR para visualizar `SERVER_BLENDER.glb` en navegador y visores VR compatibles.

## Ver localmente

Sirve la carpeta raiz del repositorio y abre:

```text
http://localhost:8000/server-vr/
```

## Publicacion

Al estar dentro del repo de GitHub Pages, la escena queda disponible en:

```text
https://caraujo1987.github.io/model/server-vr/
```

## Compatibilidad

El boton VR aparece en navegadores con soporte WebXR VR, por ejemplo Meta Quest Browser. En computador se puede inspeccionar el modelo con mouse o trackpad.
